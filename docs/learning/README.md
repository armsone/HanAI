## 개인정보 경계

- 원본 영상·사진·프레임·오디오·관절 좌표는 로컬 `Inbox/`, `Work/` 또는 대표님이 직접 전달한 로컬 경로에서만 처리하고 저장소에 넣지 않는다.

- 대규모 과거 학습 결과(예: 798개 영상 오디오 요약)는 통계 문장으로만 인용하고 원본 JSON은 복사하지 않는다.

## 2026-08-25 학습 메모

### 우천 야외 라운드 12개 전수 샘플

- 대표님이 비 오는 실제 라운드에서 촬영한 12개(총 87.92초)를 모두 확인했다. 0.2초 간격 433프레임 중 289프레임에서 자세를 얻었고, 각 클립의 전체 흐름과 최고 오디오 사건 전후 7프레임을 대조했다.
- 12개 모두 실제 골프 샷 동작이 확인됐다. 티잉 구역, 페어웨이·러프, 짧은 어프로치성 동작이 섞여 있지만 정확한 클럽 종류는 사람이 클립별로 라벨하지 않았으므로 확정하지 않았다. 퍼팅 양성은 없다.
- 첫 영상은 낮은 어드레스 한 장면 때문에 처음 퍼팅처럼 보였지만, 세부 프레임의 큰 백스윙과 높은 피니시를 확인해 짧은 어프로치성 샷으로 정정했다. **클럽은 한 프레임의 자세가 아니라 준비→백스윙→임팩트→피니시 전체로 구분한다.**
- 11번은 영상상 실제 샷이지만 최고 오디오 특징이 peak 0.1419, impactScore 0.0920에 그쳤고 배경 오디오 중앙값도 높았다. 기존 noisy 소리 기준만으로는 놓칠 수 있어, 0.7.0은 음량 문턱을 낮추지 않고 정렬된 연속 화면·자세 임팩트가 있을 때만 이와 같은 약하고 날카로운 접촉음을 살린다.
- 4번과 11번은 임팩트가 파일 시작 0.2~0.3초 부근이라 주소·백스윙 일부가 잘린다. 실제 자동 촬영에서는 롤링 pre-roll을 유지해야 하며, 짧은 파일만으로 준비 동작이 없었다고 단정하지 않는다.

### 혼합 클럽 338개 전수 샘플

- 이 결과 영상은 약 3시간 동안 여러 사람이 친 세션에서 AiShot이 담은 4초 클립 338개를 이어 붙인 1,352초 영상이다. 드라이버뿐 아니라 우드, 유틸리티, 아이언과 어프로치가 함께 있다는 대표님의 세션 정답을 반영했다. 클립별 클럽 종류와 샷·비샷 개수는 확인되지 않았으므로 만들지 않았다.
- 338개 모두에서 오디오·화면·자세 특징을 계산하고 중앙 장면을 대조했으며, 약한 후보 87개는 시작·임팩트·종료 흐름을 추가로 확인했다. 50ms 오디오 창은 27,040개, 일반 충격음 후보는 322개였고 280개 클립이 예상 임팩트 구간에서 현재 기준과 비슷한 오디오 트리거를 보였다.
- 자세 7프레임 중 3프레임 이상 이어진 클립은 282개, 7프레임 모두 얻은 클립은 154개였다. 손 이동 중앙값은 몸 너비의 2.16배였지만 하위 25%도 0.46배여서, 큰 스윙 문턱 하나로 모든 클럽을 나누면 작은 어프로치를 잃는다.
- 반복된 비샷 장면은 빈 타석·시뮬레이터 화면 전환, 사람 입퇴장·교대, 서서 기다리기·위치 조정, 공 놓기·회수·클럽 정리였다. 화면 근거가 없을 때 소리만으로 촬영하는 경로를 0.7.0에서 막되, 약한 오디오·작은 움직임 자체는 삭제 기준으로 사용하지 않는다.
- 원래 세션에는 퍼팅 상황이 있었지만 출력 영상에는 퍼팅이 없다. 이는 **퍼팅 양성 누락의 세션 단위 정답**이며, 출력만 보고 퍼팅 동작 수치나 정확도를 꾸며내지 않는다. 0.7.0 코어는 퍼팅 근거 유효 시간을 0.55초, 확정 latch를 0.60초로 맞춰 짧은 스트로크의 근거를 조금 더 오래 유지한다. 저전력·발열 상태에서도 자세 간격을 0.25초로 유지하는 앱 어댑터 변경은 향후 `릴리즈` 때 별도로 적용·검증한다.
- 오디오·화면 임계값은 클립별 정답이 없으므로 바꾸지 않았다. 다음 자료에서는 퍼팅 양성 클립과 클립별 클럽·샷·비샷 정답을 함께 확보해 재현율과 오탐률을 직접 비교한다.

## 2026-08-24 학습 메모 (이관)

### 풀스윙 샘플

- 실내 스크린 골프 AiShot 결과 영상 1개(288초, 1080×1440)를 로컬에서만 공부했다. 여러 명이 번갈아 치는 풀스윙 장면이 중심이다.
- 퍼팅은 없거나 극소수여서 **퍼팅 판정 품질을 평가하거나 개선하는 근거로 쓰지 않는다.**
- 상위 12개 순간의 오디오 특징: peak 0.89~0.96, rms 0.03~0.07, crossingRate 0.02~0.10, 직전 대비 상승 0.32~0.40. 실내 타구음은 peak가 크고 crest factor가 높다.
- 화면 요약(24프레임 샘플): 평균 움직임 0.063, 최대 0.191, 평균 밝기 변화 0.016. **실내에서는 화면 격자 움직임이 약할 수 있다.**
- 코드 교훈 → 0.5.1: 시간이 정렬된 신뢰도 높은 자세 임팩트가 약한 격자 움직임을 대신할 수 있게 하되, 충격음 판정은 항상 필수로 유지한다.

### 아이언 샘플 (negative label)

- 추가 AiShot 결과 영상 1개(544초, 1080×1440)는 **책임자가 "아이언 샷"이라고 직접 정정한 정답 라벨**로 공부했다. 원래 퍼팅으로 추정됐던 자료가 아니라 아이언이라는 사실을 보존한다.
- 특징: 긴 어드레스, 작은 왜글·예비 동작, 빠른 백스윙·다운스윙, 큰 몸통 회전과 피니시가 반복된다.
- 화면 요약: 평균 움직임 0.043, 최대 0.108 — 풀스윙 샘플보다도 약하다. 정지 화면의 낮은 어드레스 자세만으로 퍼팅을 추정하면 안 되며, 반드시 **연속 동작의 크기·속도·몸통 회전·피니시**를 함께 봐야 한다.
- 코드 교훈 → 0.6.0 `GolfPuttStrokeAnalyzer`의 아이언 반례 규칙:
  - 백스윙 폭 > 0.60 → 리셋
  - 주소 통과 복귀 속도 > 1.5/s → 리셋
  - 팔로스루 > max(0.30, peak×1.2) → 리셋
  - 몸통 속도 > 0.9/s → 어느 단계든 리셋
- 이 규칙들은 `Fixtures/golf/putt-stroke.json`의 `iron-*`, `large-*` 케이스로 고정되어 있으며 항상 `isConfirmedStroke: false`여야 한다.

### 정직한 한계

- 0.6.0 무음 퍼팅 안전망은 **대표성 있는 퍼팅 클립으로 검증되지 않았다.** 퍼팅이 아예 놓치던 문제를 줄이기 위한 보수적 안전망 설계이며, 퍼팅 양성 자료가 확보되기 전까지 실제 퍼팅 정확도는 확인되지 않은 상태다.
- 두 샘플 모두 한 장소·한 카메라 각도(세로 1080×1440)다. 야외, 다른 각도, 다른 조명은 아직 공부하지 않았다.

## 새 학습을 추가할 때

1. 원본은 `Inbox/` 또는 대표님이 직접 전달한 로컬 경로에서만 읽고, 분석 중간물은 `Work/`에만 둔다(저장소에는 원본을 넣지 않음).
2. 결과는 `identity`를 제거한 요약 JSON과 이 문서의 날짜별 메모로만 남긴다.
3. 라벨은 사람이 확인한 정답만 쓰고, 정정 이력이 있으면 그대로 적는다.
4. 판정 규칙을 바꾸면 `Fixtures/golf/`에 케이스를 추가하고 두 플랫폼 테스트를 통과시킨다.
