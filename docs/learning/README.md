# 한양 학습 노트

한양의 목적은 소리 자체를 맞히는 것이 아니라 영상·사진에서 가장 기억해야 할 순간을 찾는 것이다.
이 폴더에는 **익명화된 수치 요약과 라벨**만 둔다.

## 개인정보 경계

- 원본 영상·사진·프레임·오디오·관절 좌표는 로컬 `Inbox/`, `Work/` 또는 대표님이 직접 전달한 로컬 경로에서만 처리하고 저장소에 넣지 않는다.
- 이 폴더의 JSON에는 파일명, 자산 해시, 촬영 시각, 사람 식별 정보가 없다. 이전 프로젝트의 학습 JSON에 있던 식별 해시는 이관 시 제거했고, `identity` 필드에 제거 사실만 남겼다.
- 대규모 과거 학습 결과(예: 798개 영상 오디오 요약)는 통계 문장으로만 인용하고 원본 JSON은 복사하지 않는다.

## 2026-09-07 퍼터 전용 엔진 검증

- 추가 대형 세션도 기존 자료와 분리해 전수 스캔했다. 7,287.2초(약 2시간 1분 27초), 2160×3840 세로 영상이며 1차 오디오·화면 후보는 354개, 0.2초 Vision 포즈 샘플은 30,247개였다. 보수형 퍼터 포즈 게이트는 2,628개 후보(3초 간격 794개), 회수형 게이트는 7,231개 후보(3초 간격 1,000개)를 만들었다. 새 영상에는 기존 라벨을 섞지 않고 로컬 `Work/`에 독립 산출물을 보관한다.
- 새 영상 상위 포즈 후보를 직접 프레임 확인한 결과, 일부 상위 후보가 아이언·우드·드라이버 같은 큰 스윙이었다. 다음 큰 샷 직전이라는 약한 sequence prior를 넣어도 풀스윙이 충분히 제거되지 않아 자동 확정 규칙으로 채택하지 않았다. 새 영상 전용 `putter-engine-review-30.json`과 경계 `putter-engine-review-uncertain-15.json`을 만들어 사람 검토 큐로 분리했다.
- 새 영상의 첫 검토 45개 라벨은 퍼터 2·비샷 35·퍼터 아님 8이었다. 경계 라벨까지 Vision 참조에 연결해 재순위한 결과 643개가 계산되었고, 1:1 검증 상위 30개는 퍼터 1·음성 0·미라벨 29였다. 새 상위 30개와 경계 15개를 다시 내보내 기존 45개 라벨은 history로 보존하고 동일 후보 재질문을 막았다.

- 수치만 조절하는 반복의 한계를 줄이기 위해 역할·단일 작성자·인계 산출물·누출 방지 평가 순서를 [퍼터 엔진 다중 에이전트 개선 루프](putter-agent-loop.md)에 고정했다. 이 자료는 알고리즘 제안, 실행, 검증, 사람 라벨 환류를 분리한다.

- 전체 영상 5,286.3초와 부분 영상 258.9초를 0.2초 간격으로 전수 포즈 추출해 24,630개 샘플을 확보했다. 원본 영상·프레임은 저장소에 넣지 않고 로컬 `Work/`에서만 처리했다.
- `GolfPutterDetector`에 긴 후보 안의 실제 스트로크 중심을 다시 찾는 이동창과 전체 포즈 스트림의 순서 검증 경로를 추가했다. 주소·짧은 횡방향 왕복·몸통 고정·수직 움직임 억제를 함께 본다.
- 고해상도 라벨 구간의 조건 탐색에서는 퍼터 양성 14/16, 퍼터 아님 2/4가 후보 조건을 통과했다. 그러나 전체 전수 적용에서는 비샷과의 겹침이 여전히 커서, 이 수치를 전체 퍼터 재현율로 해석하지 않는다.
- 하단 매트·사람 영역 ROI 움직임과 약한 오디오를 결합한 후보 엔진도 구현했다. 최신 라벨 301개와 대조한 1,000개 후보에서 시간 간격을 둔 619개를 남겼고, 그 안에 퍼터 14개, 비샷·퍼터 아님 173개, 타 클럽 17개가 겹쳤다. 후보 회수에는 도움이 되지만 자동 확정기로 쓰기에는 오탐이 많다.
- 이번 검증에서 확인된 원인은 두 가지다. 첫째, 사람이 붙인 후보 시각이 스트로크 중심이 아닌 전후 장면 중심이다. 둘째, 자세·화면·오디오 각각은 비샷과 분포가 겹친다. 그래서 후보 회수와 클럽 확정을 분리하고, 30개 후보를 퍼터 30개로 간주하지 않는다.

### 2026-09-07 반복 검증 결과

- 포즈·하단 ROI 움직임·오디오로 만든 1,934개 후보 중 시간 간격을 둔 619개를 Vision 이미지 특징 비교 대상으로 만들었다. 사람이 확인한 퍼터 장면과 비샷·퍼터 아님 장면의 앞·가운데·뒤 프레임을 비교하고, 같은 라벨 구간 6초 이내 참조는 후보 점수에서 제외했다.
- 이전 실행에서 보관한 순위는 상위 30개 퍼터 5개 수준이었지만, 최신 참조 라벨 묶음으로 fresh 재실행한 기준 결과는 퍼터 1개, 비샷·퍼터 아님 4개, 타 클럽 0개였다. 하단 매트 움직임을 추가한 반복 실험은 퍼터 4개, 비샷·퍼터 아님 3개, 타 클럽 1개로 기준 결과보다 퍼터 회수는 늘었지만 아직 안정적이지 않다. 매트 신호는 진단 필드로 보존하며, 이 결과를 완성된 자동 순위로 채택하지 않는다.
- Vision 특징 영역도 비교했다. 하체·매트 `lower` crop은 상위 30개에서 퍼터 3개·비샷/퍼터 아님 5개, 손·몸통·매트를 포함한 `action` crop은 퍼터 4개·비샷/퍼터 아님 7개였다. full-frame보다 퍼터 회수는 일부 늘었지만 오탐 억제가 나빠져 기본 순위에는 아직 채택하지 않았다. crop 모드는 재현 가능한 실험 옵션으로 코드에 남겼다.
- `action` crop에 오디오 피크 -10 dB 초과 후보를 제외하는 `--quiet` 조건을 결합하고, 비샷 참조 80개를 시간순으로 전체 구간에 분산해 사용한 실행은 당시 상위 30개에서 퍼터 5개·비샷/퍼터 아님 2개·타 클럽 0개였다. 현재 라벨 파일만으로 다시 계산한 공식 수치는 퍼터 3개·비샷/퍼터 아님 1개·타 클럽 0개이며, 퍼터 회수 자체가 충분하지 않아 최종 자동 확정기로는 아직 채택하지 않고 후보 우선순위 모드로 보관한다.
- 여기에 하단 매트 움직임을 약한 tie-breaker로 넣고 ROI 감점을 강화한 `--mat` 모드를 Swift 엔진에서 재실행했다. 당시 라벨 상태에서는 상위 30개가 퍼터 5개·비샷/퍼터 아님 1개·타 클럽 0개였다. 현재 라벨 파일만 남긴 공식 검증 수치는 퍼터 3개·비샷/퍼터 아님 1개·타 클럽 0개이며, 결과는 `putter-feature-temporal-action-quiet-mat-current.json`이다.
- 공이 놓이는 하단 중앙을 좁게 잘라 전 구간의 프레임 차이 신호도 별도로 대조했다. 현재 라벨 기준으로 이 신호를 기존 최고 순위에 가중해도 상위 30개의 퍼터 3개·비샷/퍼터 아님 1개·타 클럽 0개를 넘지 못해 엔진에는 넣지 않았다. 공 ROI는 이후 다른 촬영 각도에서 재검증할 수 있는 실험 가설로만 남긴다.
- 후보 간격을 3초에서 1.5초로 줄여 619개를 801개로 확장한 실험은 상위 30개 비샷이 3개로 늘어 개선되지 않았다. 기본 후보 간격은 3초로 유지하고, 도구에는 `--spacing` 옵션만 남겼다.
- 최신 라벨의 비샷 참조 전체 223개를 사용하고, 퍼터·비샷 각각 최근접 2개 참조의 평균 거리로 순위를 계산하는 실험은 상위 30개 퍼터 4개·비샷/퍼터 아님 2개·타 클럽 0개였다. 최신 라벨을 반영한 단일 참조 기본값의 4개·5개보다 비샷을 줄여 이 조합을 현재 기본 래퍼에 채택했다. 결과는 `putter-feature-temporal-action-quiet-mat-current.json`이다.
- 비샷 참조를 같은 소스에서 6초 이내 중복되지 않도록 줄인 `--negative-gap=6` 실험은 참조 223개를 177개로 줄이면서 상위 30개 4개·2개를 유지했고, 상위 100개를 7개·12개에서 9개·11개로 개선했다. 넓은 후보 회수와 비샷 억제가 함께 좋아져 현재 기본 래퍼에 추가했다.
- 거리값만 재계산한 가중치 격자에서는 매트 tie-breaker `0.20`이 유망해 보였지만, 전체 래퍼 재실행에서는 상위 30개 퍼터가 4개에서 3개로 감소했다. 따라서 이 조합은 채택하지 않고 매트 가중치 `0.10`을 유지한다.
- 후보 프레임을 앞·가운데·뒤 3개에서 5개(`--wide-sequence`)로 넓힌 실험은 상위 30개 4개·3개, 상위 100개 7개·11개로 개선되지 않았다. 기본은 3프레임을 유지하고 넓은 시간열은 재촬영 환경용 실험 옵션으로만 남긴다.
- 손 좌우 범위·반전·몸통·수직 조건을 넓힌 회수 우선 후보군(`--recall`)은 후보를 1,934개에서 5,505개로 늘리고 라벨 후보 회수도 퍼터 14개에서 17개로 늘렸지만, Vision 후단 상위 30개는 퍼터 3개·비샷 3개로 악화됐다. 후보 확장만으로는 충분하지 않아 기본 엔진에는 반영하지 않는다.
- 초기 라벨 묶음에서는 `topk=3`이 안정적이지 않아 보류했지만, 09-07 엔진 검토 라벨을 추가한 뒤 같은 replay 조건에서 상위 30개 퍼터 15개·음성 1개, 상위 50개 15개·음성 3개, 상위 100개 17개·음성 8개로 개선됐다. 직전 `topk=2`의 14개·4개, 14개·8개, 16개·10개보다 전 구간이 좋아져 현재 래퍼 기본값을 `topk=3`으로 승격했다.
- 후보 창의 가운데 대신 손 횡방향 속도 최고 시각으로 절단 중심을 이동하는 실험도 수행했다. 상위 100개 회수는 7개에서 8개로 늘었지만 상위 30개는 4개로 감소해 기본 순위에는 적용하지 않았다. 스트로크 중심 보정은 별도 결과 `putter-feature-temporal-action-quiet-refined-0.2.json`에 남겼다.
