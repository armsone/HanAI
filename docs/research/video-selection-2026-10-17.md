# 영상 프레임·구간 선택 개선 근거

확인일: 2026-10-17 (한국 시간). 적용 범위는 HanAI이며 다른 제품에 자동 적용하지 않는다. 기존 워크플로의 중요 장면 추출·랭킹에 품질·유사도·다양성 보완을 더하는 조사다. 중요 장면 기능 자체를 새로 만든다는 의미가 아니다.

## 조사 실행과 근거 수준

공개 정보만 제공한 독립 임시 폴더에서 실제 Claude CLI를 실행했다. 요청 모델은 `claude-sonnet-5`, 실제 응답 모델도 `claude-sonnet-5`였다. WebSearch 9회와 WebFetch를 사용했고 정상 응답으로 종료했다. 비공개 소스·개인 미디어는 연구 프롬프트에 제공하지 않았다. 아래 설계는 원문에 있는 개념을 한양에 맞게 조합한 제안이며, 한양의 정확도·속도 향상 실측 결과는 아니다.

조사 결과 검토 중 논문 저자 오기와 NIQE에 BRISQUE 링크를 재사용한 오류를 바로잡았다. NIQE의 우열·실측 속도 주장은 근거에서 제외했다. 논문·모델 존재와 모바일 배포 적합성은 별개다.

## 먼저 지킬 설계 조건

1. **품질 하한을 통과한 후보에 다양성 선택을 적용한다.** MMR은 비슷한 후보의 반복을 줄이지만, 저품질 후보를 좋은 후보로 바꾸지 않는다. 품질 점수의 범위와 유사도의 범위를 맞추고, 서로 다른 점수 체계를 그대로 섞지 않는다.
2. **지역 다양성과 전체 다양성을 구분한다.** 같은 순간의 연속 프레임을 먼저 줄이고, 전체 영상·여러 사진에 걸친 반복 장면을 이후 줄인다. 동일 피사체라는 이유만으로 다른 행동·표정·사건을 모두 중복 처리하지 않는다.
3. **장면 경계와 사건을 구분한다.** 컷·디졸브 검출은 전환 지점의 근거다. 한 번도 컷이 없는 영상에도 중요한 행동이 존재하며, 전환이 많아도 하이라이트가 아닐 수 있다.
4. **프레임과 구간을 따로 평가한다.** 정지 프레임의 선명도·노출·미학 점수와 구간의 연속성·시작/끝·행동 완결성은 다르다. 움직임 크기만으로 사건의 의미를 확정하지 않는다. 좋은 한 프레임만으로 구간 전체를 높게 평가하지 않는다.

## 최소 적용 방향

기존 수치 특징 → 결측·비정상 수치 제외 → 품질 하한 → 근접 시간대 후보 정리 → 구간 점수와 시작/끝 조건 → 전체 MMR 순으로 구성한다. 모션 특징이 없으면 카메라 흔들림과 피사체 행동을 구분했다고 표시하지 않는다. feature print·시각 임베딩의 유사성은 같은 사건·인물의 동일성을 보증하지 않는다.

공통 코어는 운영체제에 의존하지 않는 숫자 특징과 거리를 입력받는다. macOS·Windows·Linux·NAS용 공통 추출 경로는 Python 표준 라이브러리와 로컬 ffmpeg/ffprobe를 사용하는 방향으로 구현하며, 기본 타일·색 분포 특징은 `perceptual-basic-v1`로 구분한다. 이 기본 특징을 Vision 임베딩이나 의미 검색과 같은 능력으로 취급하지 않는다. iOS·Android는 공통 판정 코어에 각 플랫폼의 디코딩 어댑터를 연결해야 하며 데스크톱 subprocess 실행을 그대로 가정하지 않는다.

공개 사전학습 특징을 쓰는 로컬 DINOv2·SigLIP2 어댑터는 별도 모델·리비전 namespace로 구분한다. 외부 학습 결과를 이용한 특징 비교와 텍스트 관련도는 개인 기억의 중요도를 뜻하지 않는다. 중요도 입력이 없는 기술 품질 경로는 `technical-quality-only`, 실제 텍스트 질의 관련도 입력이 있는 경로는 `text-guided-relevance`로 표시하며 기존 중요도 모델을 대체했다고 주장하지 않는다. 모델 실패를 기본 특징으로 조용히 대체하지 않는다.

Apple Vision은 선택 가능한 플랫폼 어댑터의 참고 자료이며 공통 실행의 필수 조건이 아니다. 샘플 수와 처리 크기를 제한하고, 이용할 수 없는 지표는 결측으로 남긴다. 개인 사진·영상·파일명·경로·원시 임베딩을 외부 서비스로 보내지 않는다. 사람이 선택 결과를 판단할 수 있도록 숫자 결과와 선택 이유·제약을 구분한다.

## 확인이 더 필요한 부분

- 현재 한양과 비교한 실제 프레임 선택 정확도, 구간 완결성, 놓친 사건 비율은 아직 측정하지 않았다.
- 디코딩·Vision 특징 추출의 시간·메모리·배터리 비용은 대상 기기 실측이 필요하다.
- 광학 흐름을 추가하더라도 전역 카메라 움직임과 국소 피사체 움직임의 분리는 추정이며, 패닝·줌·저조도·가림에서 실패할 수 있다.
- 수치 특징 기반 개선은 문맥을 이해하는 사건 인식 모델과 같은 능력을 뜻하지 않는다. 이번 연구는 비공개 미디어 학습·외부 전송을 승인하지 않는다.
