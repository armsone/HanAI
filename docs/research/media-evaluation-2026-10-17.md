# 한양 이미지·영상 실제 자료 비교 (2026-10-17)

이번 평가는 보관된 기존 자료에 대한 **후보 단위의 회고 평가**다. 전체 원본 영상의 새 샷 검출률이나 일반 사진 정확도를 측정한 결과가 아니다. 원본 미디어·개인 경로·인물 좌표·이미지 벡터는 이 문서와 저장소에 포함하지 않았다.

## 결론

- 새 의미 질의 순위에서 화질 비중을 줄이면 관련 후보의 순위가 개선됐다. 다만 **기존 퍼팅 전용 최종 엔진을 능가하지 못했다.** 기존 골프 전용 분석을 새 정지 화면 모델로 교체하지 않는다.
- DINOv2의 사진 유사도 순서는 Vision보다 좋아졌지만, 시험한 거리 임계값에서는 오탐이 많았다. 유사도 순위 개선과 자동 중복 확정은 별개의 결과다.
- 새 판정 코어의 가중치 제어는 Swift·Kotlin에 같이 반영했다. 실제 기기 전체, 원본 사진, 영상 전체 이벤트 재현율은 미확인이다.

## 자료와 비교 조건

- 보관된 영상 조각 716개: 조정 세션 160개, 다른 평가 세션 556개. 일부 원본은 현재 참조 경로에서 열리지 않아 남아 있는 미리보기 조각과 수치 기록으로 평가했으며 겹치는 구간이 있다.
- 기존 라벨은 조각의 후보 중심 시각에 ±0.11초로 연결했다. 조정 자료는 퍼팅 31개·기타 129개. 평가 자료에는 퍼팅 22개·기타 215개·미판정 319개가 있었다.
- 미판정 319개를 비샷이나 오답으로 간주하지 않았다. 라벨이 없는 후보까지 포함한 전체 검색 결과의 정밀도는 이 수치에서 알 수 없다.
- 기존 포즈가 충분한 공통 평가 집합은 226개(퍼팅 22개). 새 방식에서 품질 기준에 미달한 후보는 1개이고 양성 후보는 아니었다.
- 각 조각 내부 3개 프레임의 품질·DINOv2·SigLIP2 및 시간 변화 특징을 같은 방식으로 추출했다. 716개 모두 성공했다. 프레임 간 변화량은 카메라 움직임을 보정한 행동 인식 점수가 아니다.
- Gemini에는 조정 세션 160개에서 나온 익명 숫자만 제공했다. 사진·영상·원본 경로·관절 좌표와 평가 세션 자료는 제공하지 않았다.
- 조정 후보는 관련도 원점수/대조 점수와 가중치 0, 0.3, 0.6, 0.85, 1이었다. 조정 AP를 기준으로 `raw relevance, importanceWeight=1, minimumQuality=0.25`를 고정한 뒤 평가했다. 대조 질의는 더 낮아 채택하지 않았다.
- 기존 라벨은 과거 전용 엔진의 학습에도 쓰인 회고 자료다. 새 모델을 위한 전향적·미지 데이터 벤치마크라고 부르지 않는다.

## 새 의미 순위의 개선

AP는 기존 퍼팅 라벨 후보를 순위 앞쪽에 모으는 정도를 나타내는 average precision이다. 프레임 화질이나 전체 샷 검출 정확도가 아니다. 하나의 조각은 하나의 후보로 세었으며, 겹친 조각을 서로 다른 실제 샷이라고 해석하지 않았다.

조정 160개에서 기존 `0.7 × 품질 + 0.3 × 관련도`는 AP 0.1497, 상위 10개 퍼팅 라벨 0개였다. 품질 기준을 통과시킨 뒤 관련도로 정렬하면 AP 0.3136, 상위 10개 4개였다.

포즈가 충분한 공통 평가 후보 226개에서:

| 비교 방식 | AP | 상위 10개 중 퍼팅 라벨 |
| --- | ---: | ---: |
| 기존 오디오 후보 점수 | 0.0736 | 1 |
| 기존 퍼팅 **후보 함수** | 0.0920 | 0 |
| 새 의미 순위의 변경 전 가중치 0.3 | 0.0874 | 0 |
| 새 의미 순위의 조정 후 가중치 1.0 | **0.3254** | **5** |

후보 함수는 전용 엔진 전체가 아니다. 이 표만으로 기존 퍼팅 기능보다 개선됐다고 결론 내리면 안 된다. 화질 기준은 유지했으며 관련도는 개인적 중요도나 실제 타격 확률이 아니다. 실제 코어의 `scoreByIndex`를 호출해 비교했지만, 이는 공통 입력의 순위 점수 비교이며 새 파이프라인으로 긴 원본을 처음부터 다시 분석한 실험이 아니다.

## 기존 전용 최종 순위와의 별도 비교

과거의 특징 거리·시간 변화·동작·타석 변화 등을 결합한 최종 순위 기록도 남아 있었다. 라벨을 사용하지 않고 시각 차이가 작은 연결부터 ±0.11초 이내로 일대일 연결했다. 평가 세션의 연결 42개 중 32개에 판정이 있었다(퍼팅 12개). 이 **동일한 32개**에서 비교했다.

| 비교 방식 | AP | 상위 10개 중 퍼팅 라벨 |
| --- | ---: | ---: |
| 저장된 기존 전용 최종 순위 | **0.9764** | **10** |
| 새 의미 순위의 변경 전 가중치 0.3 | 0.3181 | 1 |
| 새 의미 순위의 조정 후 가중치 1.0 | 0.7599 | 8 |

기존 최종 순위는 과거 로컬 전용 분석의 저장 기록이며 이번 재실행 결과가 아니다. 현재 설치된 앱의 전체 실행 경로와 같다고 단정하지 않는다. 과거 라벨을 반영한 전용 방식이므로 이 부분 집합의 높은 수치를 전체 영상이나 새 영상에 확대하지 않는다. 그래도 현재 알려진 동일 후보에서는 전용 방식이 더 우수하므로 대체하지 않는다. 새 가중치 옵션은 텍스트로 관련 프레임을 찾는 adapter에만 적용하며 골프 전용 판정은 유지한다.

미판정까지 포함한 새 순위의 상위 조각도 로컬에서 확인했다. 이동·교대·준비 자세를 실제 스트로크보다 높게 매길 수 있었다. 2fps 확인만으로 미세한 스트로크를 부정하거나 새 정답을 추가하지 않았다. 이 관찰은 새 질의 점수를 행동 확정으로 사용하면 안 된다는 근거이며 별도의 정밀도 수치로 쓰지 않았다.

## 이미지 유사도

원본 사진의 별도 정답 집합은 확보되지 않았다. 대신 같은 장소의 영상에서 추출한 48장 중, 모델 거리 결과를 보기 전에 TM이 판정한 38쌍을 사용했다(비슷함 7·다름 31). 비슷함 중 5쌍은 빈 타석이므로 실제 인물 사진 전반의 성능을 대표하지 않는다.

| 거리 특징 | 순위 AUC | Average precision |
| --- | ---: | ---: |
| 실제 macOS Vision 기본 feature print, revision 2 | 0.8525 | 0.8160 |
| 고정 DINOv2 small | **0.9493** | **0.9127** |

AUC는 비슷한 쌍이 다른 쌍보다 가까이 정렬되는 정도이며 사진 선택 정확도가 아니다. 전처리된 동일 프레임을 사용했지만 과거 앱의 전체 사진 처리 경로를 그대로 재현한 것은 아니다.

후속으로 같은 48장을 기존 기본 픽셀 descriptor로도 처리했다(48개 모두 성공). 동일한 38쌍에서 AUC 0.7558·AP 0.5677로 DINOv2보다 낮았다. 따라서 가벼운 특징을 추가한다는 이유만으로 유사도 순위가 좋아진다고 해석하지 않는다. 이 정답은 비슷한 사진 판정이므로 별도의 중복 사본 검증 성능을 측정하는 데 사용하지 않는다.

거리 임계값 시험은 별개다. Vision 0.12에서는 7개 비슷한 쌍 모두 놓쳤고, DINOv2 0.15에서는 6개를 찾았지만 다른 31쌍 중 11쌍도 비슷하다고 판단했다(정밀도 35.3%). 이 값을 자동 중복 확정의 권장 임계값으로 채택하지 않았다. 특징 종류마다 거리가 달라 이전 임계값을 그대로 옮겨서는 안 된다.

독립 쌍 판정은 실제 기존 Swift selector와 새 JVM selector를 각각 호출하고 Gemini 평가 하네스로 계산했다. 기존의 독립 쌍 판정과 새 48장 배치 그룹 결과를 섞은 초기 진단은 비교 조건이 달라 개선 수치에서 제외했다.

## 실행·보존

- 실제 Gemini Flash low가 평가 하네스·조정 계산·가중치 제어·질의 adapter 개선을 담당했다. 상위 모델은 실행 등록 범위 문제로 시작되지 않아 사용했다고 기록하지 않는다.
- Claude는 기존 코드 호출용 평가 adapter와 로컬 숫자 추출기를 담당했다. TM은 기존 자료·라벨 연결, 실제 미디어 실행, 설정 고정과 최종 해석을 맡았다.
- Swift·Kotlin/JVM 빌드와 가중치 0/0.3/1 수치 일치, 기존 5필드 프로토콜, 결측 처리·품질 기준·잘못된 가중치 거부를 확인했다. 평가 하네스의 중복 매칭 방지·출력 보호도 숫자로 확인했다.
- Vision은 sandbox에서 실패한 뒤 정식 host 실행으로 48장 모두 처리했다. 오디오 추출기의 정수 ID·array 블록 처리 오류는 수정 후 합성 회귀와 실제 716개 실행을 통과했다.
- 원본과 기존 라벨은 변경하지 않았다. 기존 사용자 변경도 보존했다. 앱 설치·배포·커밋·푸시는 이번 작업에 포함하지 않았다.
- 익명 수치 결과와 원본을 가리키는 private manifest는 Git에서 제외된 `Work/media-evaluation`에 분리했다. 재현 시 원본 경로·좌표·프레임을 외부 에이전트에 전달하지 않는다.
- Linear의 상세 수치·구현 정보 기록은 자동 승인 심사에서 반출 위험으로 거절됐다. 연결 계정이 이슈 작성자와 같은 관리자임을 읽기 전용으로 확인한 뒤, 상세 정보 없는 최소 상태 댓글만 정상 기록했다. 상세 근거는 로컬에 유지했다.
