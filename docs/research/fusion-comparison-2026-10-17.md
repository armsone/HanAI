# 기존 전용 분석과 새 영상 분석의 결합 비교

2026-10-17 진행 기록. 전체 완료 보고가 아니다. 원본 영상·개인 경로·인물 좌표·이미지 벡터는 포함하지 않는다.

## 고정한 채택 조건

동일 조정 세션 160개 중 과거 전용 점수가 연결된 158개로 계산했다. 같은 원본의 시간순 40개씩 4개 블록을 나눠, 매번 다른 3개 블록으로만 정규화·학습하고 남은 블록을 평가한다. 원본·사건 독립 평가가 아니며 과거 라벨을 사용하는 회고 진단이다. AP를 블록별로 계산해 평균하며, 서로 다른 fold의 확률을 하나로 섞어 순위를 만들지 않는다.

사전에 정한 통과 조건은 블록 평균 AP +0.005 이상, 각 블록의 P@10·P@20 비하락, 수치 최적화 수렴이다. 기존 전문가 점수의 간격을 보존하고, 텍스트 점수는 logit 변환 후 학습 데이터의 평균·표준편차로만 표준화한다. 후보는 특징 조합 4개 × L2 3개 × 상위 보호 3개 = 36개다. 보호 개수는 절대 개수이며 블록과 전체 후보에서 차지하는 비율은 다르다.

## 정지 화면 특징의 결합: 기각

- 순위 기반 RRF의 조정 AP 상승은 약 0.000218이고 P@10·P@20 변화가 없어 실질 개선으로 채택하지 않았다.
- 전문가 점수 + SigLIP2 질의 점수 + ROI 변화량의 최고 평균 AP 후보는 0.8354 → 0.8731이었지만, 한 블록의 P@20과 다른 블록의 P@10이 낮아졌다. 36개 모두 조건을 통과하지 못했다.
- 실제 Gemini가 계산 도구를 구현·실행했고 TM의 재실행 JSON 전체가 동일했다. 기존 전문가 방식 유지를 권고했다.

## 8프레임 X-CLIP의 결합: 다른 세션에서 기각

MIT 공개 X-CLIP B/32의 리비전·가중치 해시를 고정하고 로컬 CPU에서 처리했다. 이전 SigLIP2와 같은 공개 문장 5개를 유지했다. 각 영상 조각을 8등분한 중간 시각의 프레임을 순서대로 사용했으며, 실제 디코딩 PTS는 확인하지 않았다. 단일 사진 3개를 평가했던 이전 방식과 프레임 수·모델이 달라 계산 예산이 같은 비교는 아니다.

조정 160개 추출은 모두 성공했다. X-CLIP 단독 AP는 raw logit 0.2859, 문장 집합 내 상대 softmax 0.5825였다. 해당 softmax는 실제 퍼팅 확률이 아니다. 원래 전용 점수의 AP 0.8508보다 낮아 단독 대체하지 않는다.

전문가 원점수 + X-CLIP 상대 점수의 logit, L2=10, 상위 보호=0이 블록 평균 AP 0.8354 → 0.8892로 조정 조건을 통과했다. 계수·평균·스케일·질의·모델을 고정했다. 다른 세션 556개도 모두 추출했다. 과거 전용 점수와 연결된 동일 판정 후보 32개(퍼팅 12개)에서 AP는 기존 0.9764 → 결합 0.9565로 하락했다. P@10=1.0과 P@20=0.6은 유지됐지만 AP 개선 조건을 통과하지 못해 기각했다. 조정 전체 158개에서도 P@20이 0.95 → 0.90으로 내려갔으므로 블록 평균 개선만으로 제품 채택을 정당화할 수 없다.

판정이 있는 다른 세션 237개에서 X-CLIP 상대 점수 AP는 0.2705였다. 이전 SigLIP2 의미 순위의 0.3254를 능가하지 못했다. 이 수치에는 이전 품질 기준 미달 음성 3개도 포함된다. 정확히 같은 품질 통과 후보 234개로 맞추면 SigLIP2 AP 0.3254, X-CLIP AP 0.2728, 상위 10개 퍼팅 라벨은 각각 5개·4개로 결론은 같다. 미판정 319개를 오답이나 비샷으로 처리하지 않았다.

실제 CPU 추론 중앙값은 조각당 약 0.144초였고, 8개 프레임 decode 중앙값은 약 0.60초였다. 모델 초기화는 약 4초였다. 160개 전체 125.8초, 556개 전체 425.4초로, 일부 동시 작업이 있는 단일 Mac 실행 기록이며 모바일·다른 OS·일반 성능 보장이 아니다. 최대 메모리는 측정하지 않았다.

후속으로 기존 포즈 분석의 1.6초 동작창에 맞춰 8개 프레임을 촘촘히 추출했다. 빠른 동작이 긴 조각 전체의 희소 프레임 사이에 빠질 수 있다는 가설에 대한 한 가지 고정 정책이다. 조정 160개는 127.9초에 모두 성공했다. 그러나 같은 결합 후보 36개 모두 블록별 상위 결과 보존 조건을 통과하지 못했다. 평균 AP가 가장 높은 후보는 0.8354 → 0.9158이었지만 한 블록의 P@10과 다른 블록의 P@20이 낮아졌다. 따라서 채택 후보 없이 기존 전문가 방식으로 복귀했고, 기각한 계수를 다른 세션에 반복 적용하지 않았다. 이미 관찰한 다른 세션을 독립적인 미지 평가라고 부르지 않는다.

## 앱 반영 전 필수 구분

여기서 과거 전용 점수는 `rank_putter_featureprints.swift`가 양성·음성 특징 거리와 영상/오디오 신호를 결합한 오프라인 순위 기록이다. 현재 앱의 0.7.0 오디오·동작 판정 점수와 같은 척도라고 확인되지 않았다. 따라서 이번 조정 계수를 앱의 다른 점수에 그대로 적용하지 않는다. 과거 점수 기록의 결측은 실제 검출 실패를 뜻하지 않는다.

X-CLIP adapter의 실제 CPU 추론 성공과 Android/iOS 모델 변환·기기 추론 성공도 구분한다. 앱의 실제 입력 계약과 모델 실행 경로, 빌드·설치·공개 확인이 끝나기 전에는 앱 성능 개선 또는 릴리즈 완료로 보고하지 않는다.


## 첫 비교 시점의 결정과 실제 수정

이번 결합 실험들에서는 기존 전용 순위를 대체하거나 앱에 기본 적용할 성능 개선을 확인하지 못했다. 반복 탐색으로 평가 세션에 맞춰 수치를 올리지 않는다. 앱 반영·릴리즈의 성능 조건은 충족되지 않았으며, 앱 수정·설치·배포·커밋·푸시는 수행하지 않았다. 이는 사용자에게 새 승인을 요구하는 상태가 아니라 채택 근거가 부족한 상태다.

추출 과정에서는 회전 메타데이터 처리 결함을 수정했다. ffmpeg 자동 회전과 수동 필터가 겹치지 않게 하고, display matrix의 반시계 방향 값을 내부 시계 방향 규약으로 바꿨다. 실제 회전 메타데이터 0/90/180/270도의 합성 영상과 디코더 3개를 비교한 12개 경우에서 픽셀 불일치가 0이었다. legacy `tags.rotate`는 기존 처리를 유지했으며 실제 코덱 호환성은 미확인이다. [ffmpeg 공식 회전 옵션](https://ffmpeg.org/ffmpeg.html#Video-Options)

이 결함 수정은 순위 정확도 상승 증거가 아니다. 기존 평가 조각 716개는 TM의 ffprobe 조회에서 회전 메타데이터가 모두 0이었으므로 위 순위 비교와 혼동하지 않는다. Claude가 수정·합성 확인을, Gemini가 안전한 시간창 추출기를, TM이 기존 자료 실행·조건 고정·해석을 담당했다.

원본 전체 영상 3개는 현재 참조 경로에 없고 정확한 기존 파일명의 Spotlight 색인 조회에서도 찾지 못했다. 색인 결과가 다른 복사본의 부재를 증명하는 것은 아니다. 보존된 조각과 수치 기록을 이용한 이번 후보 비교를 현재 앱의 전체 원본 처리나 실시간 자동촬영 재현으로 승격하지 않는다. 원본·기존 라벨·사용자 작업은 보존했다.


## 재개 후 추가 비교

사용자 후속 지시로 보수적인 상위 후보 제한 결합과 X-CLIP B/16 zero-shot 32프레임 모델도 추가했다. 원래 점수 간격을 보존하고 최대 순위 이동을 제한하는 48개 고정 후보를 조정 자료에서만 선택했다. 선택한 설정을 기존 평가에 그대로 적용한 결과 AP는 0.976389로 동일했으며 P@10=1.0·P@20=0.6도 유지됐다. 개선이 없으므로 영상 전용 순위의 기본 교체는 하지 않는다. 이미 관찰한 평가 자료를 미지의 독립 평가라고 부르지 않는다.

B/16의 블록 평균이 좋아진 일반 결합도 조정 전체 P@20을 0.95에서0.90으로 낮춰 평가 전에 기각했다. 반복적인 평가 임계값 조정으로 개선량을 만들지 않았다. 실제 영상 검출·사건 순위·내보내기 구간을 유지하면서, 대표 썸네일 프레임을 가까운 시각의 더 선명한 후보로 보완하는 앱 연결을 진행한다. 이 보완의 실제 결과와 앱 공개 상태는 완료 후 별도로 기록한다.

사진에서는 별도 보정 자료에서 고정한 DINO 거리 상한을 기존 지문의 AND 거부 보조로 쓰는 제한적 개선을 확인했다. [동일 입력·네이티브 비교와 한계](native-parity-2026-10-17.md)를 따른다. 앞선 영상 후보 기각은 전체 사진·영상 고도화 업무의 종료를 뜻하지 않는다.
